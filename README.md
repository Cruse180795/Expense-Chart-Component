# Expenses Chart Component

A responsive spending chart that shows the last 7 days of expenses as a bar chart, built from a Figma design.

## Features

- Bar chart rendered from a local `data.json` file
- The highest spending day is highlighted automatically (shown as blue)
- Hover states on each bar, with a tooltip showing the amount
- Responsive layout that adapts from mobile to desktop

## Built with

- React
- TypeScript
- Chart.js (via `react-chartjs-2`)
- Tailwind CSS
